⭐ Projeto em Destaque — FarmaBot

Bot de atendimento automatizado para farmácia via WhatsApp, com IA e dashboard de métricas.

O FarmaBot é um atendente virtual completo para farmácias: o cliente conversa pelo WhatsApp, navega pelo catálogo, monta o carrinho, informa endereço e segue para o pagamento — com transferência para atendente humano quando necessário.

Principais funcionalidades:

  • Atendimento via WhatsApp com máquina de estados por sessão
  • Catálogo com 6 categorias e 14 produtos
  • Carrinho, endereço, pagamento e handoff para humano
  • Respostas dinâmicas com Groq Llama 3.3
  • Dashboard de métricas (pedidos, clientes, KPIs) em React
